# 积分商城用户守则

**版本：1.0**  
**适用对象：** 积分商城所有账号持有人  
**适用范围：** 学生端、教师端及管理员端的账号与平台功能

## 一、账号与密码

1. 仅使用本人账号。账号不得转借、转让或冒用；不得尝试登录、查看或操作他人账号。
2. 妥善保管密码，不在公共设备上保存登录状态。发现密码泄露或账号异常时，应尽快联系学校老师或管理员。
3. 修改密码时应使用本人知晓且符合页面密码要求的新密码；不得故意设置为他人可轻易猜到的信息。

## 二、积分与兑换

1. 积分用于学校认可的学习激励与奖励活动，不具有现金价值，不得私下买卖、转让或兑换现金。
2. 不得通过虚构表现、重复提交、冒用身份、篡改请求或利用系统漏洞获取积分或商品。
3. 兑换前应核对商品、数量与积分价格。实物商品按页面提示等待教师发放；网络商品仅用于本人学习，不得未经许可传播受限资料。
4. 对积分、兑换或发放记录有疑问时，应及时向教师或管理员反馈，不得自行尝试修改数据。

## 三、文明使用与内容规范

1. 使用平台时应尊重师生，遵守学校规章制度与课堂秩序。
2. 不得发布或传播违法、欺凌、骚扰、歧视、暴力、色情、侵犯隐私或其他不当内容。
3. 不得利用平台进行未经学校审核的商业推广、广告、募捐或外部活动宣传。
4. 启幕宣传页等校园宣传内容须经授权人员审核后发布；发现不准确、不适宜或失效内容，请联系管理员。

## 四、系统安全与区域权限

1. 不得恶意干扰、扫描、攻击平台，不得尝试绕过登录、角色或区域权限访问未授权数据。
2. 仅在本人职责和授权区域内使用教师或管理员功能。不得查询、导出、传播与工作无关的学生信息。
3. 发现漏洞、数据异常、账号被盗或未经授权访问时，应立即停止相关操作并向学校管理员报告；不得继续利用或公开扩散漏洞。

## 五、隐私与数据使用

1. 平台会处理完成登录、积分记账、兑换履约、权限管理与安全维护所必需的账号和操作数据。
2. 用户不得擅自收集、截图传播或另作他用地处理他人姓名、学号、积分及兑换记录。
3. 数据访问遵循角色与区域授权。用户仅可访问完成其学习或工作所需的信息。

## 六、违规处理

违反本守则或学校相关规定时，学校可根据实际情况采取提醒、撤销不当积分或兑换、暂停账号、调整权限等措施；涉及严重违规的，按学校制度处理。

## 七、守则更新

学校可根据平台功能与管理要求更新本守则。重大调整时会通过平台或校内渠道告知。继续使用平台前，应阅读并确认适用版本。

## 八、联系与反馈

如有账号、积分、内容或安全问题，请联系任课教师、班主任或学校指定的平台管理员。

---

本守则用于规范校内平台使用，不替代学校正式规章制度或适用法律法规。
