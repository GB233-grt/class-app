## v1.1.0 · 校园区域权限与课堂功能

本次更新扩展了校园积分商城的**区域权限**与教师课堂工具，并完善了学生体验、安全提示和测试流程。

- **区域隔离与超级管理员**：按校区、年级、班级组织区域；教师和区域管理员只能管理获授权区域及其子区域；超级管理员管理全校区域、授权和角色。
- **启幕宣传页**：审核后发布校园宣传内容，支持图片、跳转、展示频次、受众、区域及生效时间；多条内容按顺序展示。
- **课堂模式**：全屏随机点名，即时加减分，支持键盘快捷操作，适合投屏。
- **Excel 批量加分**：支持拖放上传、公式实时校验、逐行预览及错误行筛选。
- **学生记录分页**：兑换记录和积分明细支持按需加载更多；首页汇总由数据库聚合，避免分页后统计不完整。
- **登录与守则**：登录前必须勾选用户守则；守则页面可未登录公开访问。新增登录失败限流。
- **启幕宣传管理**：已发布内容可按权限下线修改；管理员可直接编辑已发布内容，保存后立即生效。
- **README 与 Wiki**：双语 README 首屏更新，增加三端截图和演示 GIF；补充贡献指南、Issue 模板及 Wiki 内容。

### 升级说明

**已有数据库**：按顺序执行尚未运行的迁移；本版本新增的数据库迁移为：

| 文件 | 用途 |
| --- | --- |
| `15_regions_and_rbac.sql` | 区域表、区域成员授权、学生区域字段与角色扩展 |
| `16_student_summary.sql` | 学生兑换件数与消耗积分汇总函数 |
| `17_fix_rls_for_super_admin.sql` | 修正 RLS 管理员判断，使超级管理员可读取受保护的数据 |
| `18_promo_pages.sql` | 启幕宣传页表及审核、发布状态字段 |

从较早版本升级的数据库，请按顺序补跑所缺迁移，并确认最早的管理员账号已设为 `super_admin`。详细步骤见[数据库与迁移 Wiki](https://github.com/GB233-grt/class-app/wiki/数据库与迁移)。

**全新数据库**：运行 `database/all-in-one/step1-schema.sql` 后，还需执行 `database/migrations/18_promo_pages.sql`；`step1-schema.sql` 尚未包含启幕宣传页表。

部署代码前，请确认 Cloudflare Pages 的 Supabase 环境变量已配置。启幕宣传页外链默认接受 `http` / `https`，具体发布内容仍需管理员审核。

### 已知限制

- 启幕宣传页图片使用 HTTPS URL 或站内路径；当前没有图片上传功能。
- 启幕宣传页只展示排序靠前且符合频次、角色、区域和生效时间条件的内容。
- 下载次数限制字段目前仅保存，没有实际下载计数代理。
- 登录失败限流是 Cloudflare Pages Function 内存级防护，不是跨实例的全局限流。
